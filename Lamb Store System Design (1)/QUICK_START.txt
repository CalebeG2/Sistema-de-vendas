🚀 COMO RODAR LOCALMENTE EM 2 TERMINAIS:

1️⃣ TERMINAL 1 - BACKEND:
   ──────────────────────────────
   cd back
   npm install
   npm run dev

   ✓ O servidor inicia em: http://localhost:4000
   ✓ Se o PostgreSQL estiver ativo, o banco `lamb_store` e todas as tabelas são criados automaticamente (ou rode `npm run db:setup`).
   ✓ Se o PostgreSQL não estiver rodando, o backend utiliza automaticamente persistência local em JSON sem erros!

2️⃣ TERMINAL 2 - FRONTEND:
   ─────────────────────────────
   cd front
   npm install
   npm run dev

   ✓ O frontend abre em: http://localhost:5173

📡 PRINCIPAIS ENDPOINTS DA API:

   Produtos:
   ├─ GET    /api/products               (listar todos)
   ├─ POST   /api/products               (criar novo)
   ├─ PUT    /api/products/:id           (atualizar produto)
   ├─ PATCH  /api/products/:id/stock     (ajustar estoque)
   ├─ GET    /api/products/:id/movements (histórico de movimentações)
   └─ DELETE /api/products/:id           (excluir produto)

   Lançamentos do Dashboard:
   ├─ GET    /api/dashboard/entries      (listar lançamentos manuais)
   ├─ POST   /api/dashboard/entries      (inserir valor/lançamento)
   ├─ PUT    /api/dashboard/entries/:id  (editar lançamento)
   └─ DELETE /api/dashboard/entries/:id  (excluir lançamento)

   Designs DTF:
   ├─ GET    /api/designs                (listar todos)
   ├─ POST   /api/designs                (criar novo)
   ├─ PUT    /api/designs/:id            (atualizar design)
   ├─ PATCH  /api/designs/:id/stock      (atualizar estoque do DTF)
   └─ DELETE /api/designs/:id            (excluir design)

   Pedidos / Kanban:
   ├─ GET    /api/orders                 (listar todos)
   ├─ POST   /api/orders                 (criar pedido)
   ├─ PATCH  /api/orders/:id/status      (mover coluna no Kanban)
   └─ DELETE /api/orders/:id             (excluir pedido)
